## Installation

1. **Clone the repository**
```bash
git clone https://github.com/Chloelee05/SMU_datathon/
cd chatgpt-clone-ui
```

2. **Install dependencies**
```bash
pip install -r requirements.txt
```

4. **Set OPENAI_API_KEY**
```bash
pip install -r requirements.txt
```

4. **Run the application**
```bash
streamlit run app.py
```

5. **Open in browser**
```
http://localhost:8501
```
